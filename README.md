---

## Sobre os dados

Os sistemas abaixo rodam sobre dados reais de empresa e de pesquisa acadêmica. **Nada disso está
aqui.** Sem leads, sem contatos, sem CNPJs, sem CSVs operacionais, sem o dataset da pesquisa.

O que está publicado é o que eu projetei: a arquitetura, as especificações dos agentes, as regras de
segurança e o desenho dos pipelines.
